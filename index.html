// About Me

The Journey

I'm Syed Mohammad Hamzah, an aspiring data scientist and machine learning practitioner based in India, passionate about extracting actionable intelligence from complex, real-world data.

During my Data Science internship at Sipher Web Pvt. Ltd., I built an end-to-end analytical pipeline and interactive dashboard covering 20 years of Indian Lok Sabha elections, which was honored with the Best Project award.

As part of the AB Talks 60-Day Claude AI Challenge, I designed and deployed the Healthcare Efficiency Explorer, evaluating spending vs. life expectancy across ~193 nations using World Bank Open Data.

My current active focus is Machine Learning — mastering supervised and unsupervised learning algorithms, model evaluation metrics, and scikit-learn pipelines to build predictive models that solve genuine problems.
